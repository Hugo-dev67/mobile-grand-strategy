# Empire Pulse

A mobile-friendly grand-strategy strategy prototype inspired by classic world-power management games.

## Play it locally

1. Open `index.html` directly in a browser, or
2. Run a local web server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Hex-like strategic map with interactive nation selection
- Resource, industry, army, navy, and technology management
- Turn-based AI rivals and diplomacy pressure
- Touch-first mobile layout
- War, diplomacy, mobilization, and research actions

## Controls

- Tap a nation on the world map to select it
- Use the command buttons to research, mobilize, trade, or declare war
- End each turn to resolve income and AI actions

## Design notes

This is a compact, original prototype rather than a direct HOI4 clone. It captures the feel of grand strategy with a fast, playable loop and a mobile interface.
